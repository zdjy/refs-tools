# 08: 主观阅卷与成绩汇总

**What to build:** 授权阅卷员可以处理待阅主观题，考生可查看符合披露策略的成绩；管理员改判不会抹去原始评分历史。

**Blocked by:** 07: 正式考试与答卷提交

**Status:** ready-for-agent

- [ ] 阅卷队列仅显示授权考试范围内的待阅答卷，答卷媒体按权限短时访问。
- [ ] 阅卷分数限制在题目满分范围内，评语随评分提交并保留操作人和时间。
- [ ] 阅卷完成后按考试快照中的公式及成绩汇总策略重新计算结果。
- [ ] 管理员改判需填写理由，保留原分、改判分、理由、操作者和时间。
- [ ] 考生只可查看本人结果，且服务端按考试披露策略裁剪反馈。
