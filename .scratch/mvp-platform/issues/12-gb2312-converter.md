# 12: GB 2312 区位码工具

**What to build:** 用户可以进行汉字与区位码双向查询，并转换相关编码表示或批量处理文本；无法表示的字符得到明确反馈。

**Blocked by:** None (can start immediately)

**Status:** implemented-awaiting-manual-acceptance

- [x] 支持汉字与区位码双向查询，并展示区位码、国标码和十六进制机内码等表示。
- [x] 支持英文、数字和符号输入，并明确其与汉字区位码的区别。
- [x] 支持批量文本转换，非法输入和 GB 2312 未收录字符有可识别的结果。
- [x] 工具数据或标准实现来源符合许可要求，并有双向往返和边界测试。
