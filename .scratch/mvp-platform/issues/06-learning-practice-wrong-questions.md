# 06: 学习资料与练习错题闭环

**What to build:** 用户可以浏览已发布学习资料、进行练习并复习错题；内容编辑可以管理资料和题目，历史版本不会被后续编辑改写。

**Blocked by:** 02: 作用域权限与审计、03: 媒体直传与访问授权

**Status:** partial（Task 9 资料后端已实现，Task 10/14 与学习 UI 待完成）

- [ ] 用户可浏览最多三级分类下的已发布资料；资料可挂多个分类并按下载策略授权媒体。（API 已实现，学习 UI 待完成）
- [ ] 编辑可以创建、发布、修订和下线资料；发布版本不可变，引用媒体必须已核验。（API 已实现，学习 UI 待完成）
- [ ] 用户可进行顺序或随机练习并即时获得客观题反馈；客户端响应不暴露 answer key。
- [ ] 练习历史保留；错题连续答对两次后移出错题本，中途答错则连续次数归零。
- [ ] 收藏和最近访问以服务端为准；缓存不包含私有媒体或敏感个人答题数据。
