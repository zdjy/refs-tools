# 05: 组织认证与平台认证

**What to build:** 裁判可以提交组织或平台认证申请并通过相应范围的人工审核；认证档案、申诉和证书原件访问遵守权限边界。

**Blocked by:** 03: 媒体直传与访问授权、04: 组织申请与成员管理

**Status:** ready-for-agent

- [ ] 组织认证仅适用于本组织正式成员，并由本组织授权认证员审核；申请人不得审核本人申请。
- [ ] 平台认证申请要求当前有效组织认证和成员关系，由平台授权审核员独立审核。
- [ ] 证书原件保持私有，只有申请人和对应审核范围人员可取得短时访问授权。
- [ ] 认证级别仅用于展示、筛选和记录，不被自动排序或推断高低。
- [ ] 撤销、暂停、补件和申诉遵循状态规则；申诉复核人与原审核人分离，历史结果保留并审计。
