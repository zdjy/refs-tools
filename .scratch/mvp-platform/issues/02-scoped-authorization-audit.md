# 02: 作用域权限与审计

**What to build:** 用户对平台、组织、赛事和比赛资源的访问由服务端按当前角色、作用域和资源状态决定；敏感业务操作可追溯。

**Blocked by:** 01: 邮箱登录与会话

**Status:** ready-for-agent

- [ ] 受保护资源默认拒绝，API 对每次读写执行对象级和作用域授权。
- [ ] 跨组织访问和已撤销权限的请求被拒绝，不因旧会话声明继续授权。
- [ ] 规格列出的高风险权限及业务状态操作写入追加式审计记录。
- [ ] 审计记录不包含密码、验证码、签名 URL 或媒体内容，业务用户不能修改或删除记录。
