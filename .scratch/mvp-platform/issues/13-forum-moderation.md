# 13: 论坛与内容治理

**What to build:** 已验证用户可以在论坛浏览、发帖、回复和互动；附件经基础校验后才发布，版主能够处理举报、内容和申诉。

**Blocked by:** 02: 作用域权限与审计、03: 媒体直传与访问授权

**Status:** ready-for-agent

- [ ] 用户可浏览板块与帖子并执行规格范围内的回复、点赞、收藏和举报。
- [ ] 发帖与回复使用白名单富文本，服务端再次清洗危险标签和链接。
- [ ] 附件须为已核验对象且通过类型和大小检查，否则不得发布。
- [ ] 作者限时编辑和软删除符合规则；版主可隐藏、恢复和处罚，相关操作可审计。
- [ ] 用户可提交治理申诉；处理权限受限且申诉结果可追溯。
