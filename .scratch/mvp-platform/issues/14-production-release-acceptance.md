# 14: 部署与发布验收

**What to build:** 首发版本可通过生产静态站点和轻量 API 部署运行，核心正式功能及纳入发布的 Beta 功能通过权限、安全、数据保留和运行资源验收。

**Blocked by:** 01–13 中纳入首发发布的全部 tickets 完成

**Status:** ready-for-agent

- [ ] 客户端和管理端以静态 SPA 产物部署，API 独立轻量运行，生产环境不依赖 Node.js 前端服务。
- [ ] 权限矩阵、跨组织访问拒绝、角色撤销即时生效、媒体生命周期和关键状态并发通过验收。
- [ ] 生产配置不包含真实凭据；TLS、数据库连接上限、对象存储权限和日志脱敏符合项目约束。
- [ ] 单元测试与静态检查通过；单测内存预算低于 300 MB，生产构建不要求在 2C2G 主机执行。
- [ ] 实际纳入首发的路由、功能开关、离线与过期状态及静态 SPA 路由通过发布 smoke test。
