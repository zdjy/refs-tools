# 01: 邮箱登录与会话

**What to build:** 用户可以使用邮箱验证码注册和登录，并在需要时设置密码登录；会话可安全恢复，未验证邮箱不能执行受限业务操作。

**Blocked by:** None (can start immediately)

**Status:** implemented

- [x] 邮箱验证码具备过期、一次性使用、尝试次数和发送频率限制，响应不泄露邮箱是否已注册。
- [x] 用户可注册、验证码登录、可选密码登录，并能安全使用和结束会话。
- [x] 未验证邮箱的用户无法执行规格要求邮箱验证的核心操作。
- [x] 重复绑定凭据、过期验证码和重放请求均被拒绝并有测试覆盖。
