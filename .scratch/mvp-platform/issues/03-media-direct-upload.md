# 03: 媒体直传与访问授权

**What to build:** 用户可以在授权范围内从浏览器直传媒体到对象存储，并在需要查看时取得短时访问授权；未经核验的对象不会进入业务流程。

**Blocked by:** 02: 作用域权限与审计

**Status:** ready-for-agent

- [ ] 上传意图按用户、资源作用域、用途、类型和大小策略校验后签发短时授权。
- [ ] 媒体字节只在浏览器与对象存储间传输，API 不代理或缓冲媒体内容。
- [ ] 上传完成经服务端对象元数据核验后才标记可用；事件和完成请求可幂等重试。
- [ ] 读取和删除按当前资源授权执行；敏感媒体访问和删除按要求审计。
- [ ] 数据库、日志和默认缓存不保存签名 URL 或存储凭证。
