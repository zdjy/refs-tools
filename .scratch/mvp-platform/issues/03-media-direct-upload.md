# 03: 媒体直传与访问授权

**What to build:** 用户可以在授权范围内从浏览器直传媒体到对象存储，并在需要查看时取得短时访问授权；未经核验的对象不会进入业务流程。

**Blocked by:** 02: 作用域权限与审计

**Status:** implemented-partial-awaiting-provider-and-business-integration

- [x] 上传意图按用户、资源作用域、用途、类型和大小策略校验后签发短时授权；未实现的考试/赛后业务目标默认拒绝。
- [x] 媒体字节只在浏览器与对象存储间传输，API 不代理或缓冲媒体内容。
- [x] 上传完成经服务端对象元数据核验后才标记可用；事件和完成请求可幂等重试。
- [x] 当前已接入范围的读取和删除按实时资源授权执行并审计；留存证据默认禁止通用删除。
- [x] 数据库、日志和默认缓存不保存签名 URL 或存储凭证。
- [ ] 真实 OSS CORS/禁止覆盖/生命周期/事件桥联调。
- [ ] 所属业务模块接入学习发布后读取、认证审核员读取、考试和赛后材料权限及留存审批。
- [ ] 完整业务页的预览/原图交互、原生键盘与系统 reduced-motion/视觉验收。
