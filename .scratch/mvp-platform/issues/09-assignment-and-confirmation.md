# 09: 赛事选派与岗位确认

**What to build:** 已审核组织的组织者可以创建比赛并人工选派本组织成员；裁判可以响应岗位邀请，岗位名单变更保留完整替换历史。

**Blocked by:** 04: 组织申请与成员管理、05: 组织认证与平台认证

**Status:** ready-for-agent

- [ ] 组织者可创建赛事、比赛和预置岗位，并只从所属组织正式成员中选择候选人。
- [ ] 候选人资格信息用于提示和筛选，不自动排序；越过岗位认证范围提示须填写理由并二次确认。
- [ ] 发布岗位名单后普通编辑不能改变岗位结构；裁判可接受或拒绝并记录状态与时间。
- [ ] 替换、取消及赛程地点变更遵循专门状态流程，并按规则要求重新确认岗位。
- [ ] 资格例外、发布和岗位状态变化记录当时资质快照并审计。
