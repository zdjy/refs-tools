# 04: 组织申请与成员管理

**What to build:** 用户可以申请创建或加入组织；平台审核通过后组织才能开展业务，组织负责人可以管理成员与允许的组织角色。

**Blocked by:** 01: 邮箱登录与会话、02: 作用域权限与审计

**Status:** in-progress

- [ ] 用户可提交组织创建申请；未审核组织无赛事、选派、认证审核或角色授予等运营权限。
- [ ] 平台管理员可审核组织申请；有效的平台创建邀请码与组织成员邀请码用途隔离。
- [ ] 用户可通过邀请、成员邀请码或自主申请加入组织，流程按规格要求确认或审核。
- [ ] 组织负责人可授予和撤销允许的组织角色；成员退出或移除后权限立即失效，历史关系保留。
- [x] 组织冻结限制新业务并保留历史只读数据；关键治理操作可审计。

## Comments

- 本轮交付平台组织治理首期，见 [FS-0015](../../../docs/specs/0015-admin-organization-management.md)：管理端查询/详情、代录待审申请、审核通过/驳回、冻结/解冻；通过审核时原子建立负责人成员及默认角色。用户自助申请、两类邀请码、成员与组织角色管理、所有权转移仍待实现，因此不勾选完整平台审核条目或关闭 ticket。
