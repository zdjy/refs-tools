# 07: 正式考试与答卷提交

**What to build:** 编辑可以发布具有不可变题目和规则快照的考试；符合条件的用户可以参加考试，断线后恢复服务端已保存答卷并按服务端规则提交。

**Blocked by:** 03: 媒体直传与访问授权、06: 学习资料与练习错题闭环

**Status:** ready-for-agent

- [ ] 考试发布前校验题目、媒体、时间窗口、报名条件、分值权重和成绩规则完整有效。
- [ ] 发布后题目版本、答案、解析、分值和考试策略形成不可变快照。
- [ ] 符合邮箱验证及考试资格条件的用户可启动唯一活动尝试，服务端时间决定截止时间。
- [ ] 答案逐题保存并以服务端 revision 防止乱序覆盖；断线恢复只恢复服务端确认版本且计时不暂停。
- [ ] 交卷、尝试次数消耗和答案冻结具备原子性及幂等性；宽限窗口结束后拒绝更改。
- [ ] 主观题图片仅能引用已核验私有媒体；空题按规则计零分。
