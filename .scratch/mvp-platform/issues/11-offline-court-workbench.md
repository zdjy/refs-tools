# 11: 离线比赛工作台

**What to build:** 裁判可在设备本地使用比赛计时、犯规与事件记录工具；页面切换或锁屏后状态可恢复，并能导出或清理会话。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 计时器支持开始、暂停、恢复和重置，并以时间戳恢复，不依赖后台 JavaScript 定时器。
- [x] 本地会话支持比赛/进攻/暂停计时、球队犯规、可配置秒数快捷设置和操作日志；提示不替代最终裁决。
- [x] 新会话固定当时的节数与计时参数；历史会话恢复时继续使用原有配置。
- [x] 用户可导出、删除单个会话或清空本地数据；存储不可用或空间不足时明确提示。
- [x] 会话不自动同步到业务比赛记录，并提示共享设备的数据风险。
