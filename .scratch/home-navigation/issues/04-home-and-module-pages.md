# 04：首页、学习入口、工具目录与建设说明

**Status:** completed

**Blocked by:** 03：共享导航与存量页面返回首页。

**What to build:** 将任务 01 的页面骨架完善为用户可使用的首页及导航页面，并接入准确的身份状态反馈。

## 必读

- [FS-0006 §3～5、§7、A03、A05、B01、B06、B08](../../../docs/specs/0006-home-navigation.md)。
- [共享 UI 规范](../../../docs/ui/macos_fiba.md)。
- [编码规约索引](../../../docs/agents/coding-standards.md)中的通用、前端与样式主题。

## 实施步骤

1. 完成首页主操作区的固定标题、说明和两个导航链接；学习入口附近明确建设状态。
2. 完成三组共 8 张模块卡片，按 FS-0006 固定顺序消费导航配置，不增加假业务摘要。
3. 完成学习入口页的资料范围说明及练习、错题、考试、考试历史与成绩入口。
4. 完成工具目录：本地工作台可进入，GB 2312 为建设中；展示本地数据及离线能力边界。
5. 完成建设说明：标题、可用性、范围摘要、相关链接及返回首页，不承诺日期或提供不可用业务操作。
6. 在共享导航身份区复用 auth store，区分 unknown/loading、anonymous、authenticated、error；网络失败不隐藏页面，重试不建立新状态源。
7. 不在首页或目录实例化工作台 store，不新增 API、持久化、Service Worker、依赖或虚构通知数量。
8. 补身份区/展示投影的轻量测试，执行相关检查及移动、桌面视觉验证。

## 预期文件

## 验收

- [x] 首屏可发现工作台入口，点击不自动创建或启动比赛。
- [x] 8 张卡片、学习子入口和两个工具均可导航，状态和文案符合规格。
- [x] 建设说明可未登录阅读；没有假数据、假按钮或无依据的上线日期。
- [x] 身份恢复时不闪现匿名态，失败可重试，长显示名称不破坏布局。
- [x] 首页、学习入口、目录及建设说明无对不存在业务接口的请求。
- [x] 单列/双列/三列切换符合规格，使用统一 token、断点和交互状态。
- [x] 相关单测、类型检查、构建及样式检查通过。
