# 02：工作台页面往返状态安全

**Status:** completed

**Blocked by:** 无，可独立开始；不依赖首页 DOM，任务 03 接入可见导航前必须完成。

**What to build:** 消除新增首页导航带来的重复初始化和未保存内存数据覆盖风险，保持原有计时与本地持久化边界。

## 必读

- [FS-0006 §6、A06、B07](../../../docs/specs/0006-home-navigation.md)。
- [队伍级记录台规格](../../../docs/specs/0003-team-scorer-console.md)。
- [ADR 0008](../../../docs/decisions/0008-client-state-and-routing.md)。
- [编码规约索引](../../../docs/agents/coding-standards.md)中的通用与前端主题。

## 实施步骤

1. 核对 `src/application/workbench-state.ts`、`src/stores/workbench.ts`、工作台视图及存储 ports 的所有权和生命周期。
2. 先添加重复初始化、保存失败后再次进入、读取失败后重试等状态级回归用例，不挂载完整 UI 或引入重型 DOM 依赖。
3. 使成功初始化后的再次进入不重新读取快照；首次读取失败仍通过明确重试读取恢复。初始化是否完成不能只靠“是否有会话”判断，空快照也属于成功读取。
4. 再次进入时使用原有时间戳语义结算运行时钟；保持单个周期任务，不自动停表、重置或重复写到时事件。
5. 验证重试保存、导出、删除及清空失败处理不回归，应用销毁释放周期任务和 ports。
6. 保留存储键、规则快照、导出格式及现有同步边界，不为了首页摘要新增存储读取接口。

## 验收

- [x] 首次初始化读取一次；成功读取空快照后再次初始化不重复读取。
- [x] 读取失败不覆盖原数据，重试仍可恢复；错误状态不被误标成初始化成功。
- [x] 模拟保存失败后再初始化，当前内存比分、日志、会话和错误提示保留，重试与导出可用。
- [x] 运行时钟经过模拟时间后再次进入正确结算，到时事件不重复。
- [x] 多次进入不会增加周期任务，销毁时正常释放。
- [x] 既有工作台测试通过，无存储协议或规则版本变更。
- [x] 明确记录：此任务不能保证未保存数据跨整页刷新保留。

## Comments

四项新增回归先复现失败，增加初始化尝试门槛、显式读取重试后结算，修正后通过。验证空快照、失败保存往返、读取重试、时间戳到时和单个周期任务；浏览器验证 3 分运行往返、保存失败后 5 分往返、重试及导出。详见 FS-0006 §11。未保存数据仍不保证跨整页刷新保留。
