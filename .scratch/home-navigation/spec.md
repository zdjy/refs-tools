# 裁判端首页与模块导航开发入口

**Status:** implemented-awaiting-manual-acceptance

唯一功能规格：[FS-0006：首页与模块导航](../../docs/specs/0006-home-navigation.md)。本文只维护任务顺序，不复制产品规则或工程规约。

## 开始前

1. 完整阅读 FS-0006 及任务涉及的规格、ADR；按[编码规约索引](../../docs/agents/coding-standards.md)的阅读顺序执行。
2. 核对 Git 工作区，保留无关用户改动。
3. 首版仅交付首页、导航、工具目录、建设说明及工作台往返安全；不顺带实现其他模块或 PWA。
4. 当前 ADR 0008 仍记录根路径跳转工作台，任务 01 实施时同步记录后续变更；不能把开发计划当作已经上线。

## 任务顺序

| 顺序 | Ticket | 前置条件 | 可验证交付 |
| --- | --- | --- | --- |
| 1 | [01 路由与导航定义](issues/01-route-navigation-contract.md) | 无 | 显式路由、导航单一来源及可构建视图骨架 |
| 2 | [02 工作台往返状态安全](issues/02-workbench-navigation-safety.md) | 无，可与 01 独立准备 | 重复进入不覆盖未保存数据，计时和资源生命周期测试通过 |
| 3 | [03 共享导航与返回入口](issues/03-shared-navigation.md) | 01、02 | 主导航、移动底栏、存量页面回首页 |
| 4 | [04 首页与模块页面](issues/04-home-and-module-pages.md) | 03 | 完整首页、学习入口、工具目录、建设说明及身份反馈 |
| 5 | [05 综合验收](issues/05-acceptance.md) | 01～04 | 自动化及浏览器检查、体积变化和限制记录 |

可由一个开发者按 01 → 02 → 03 → 04 → 05 顺序执行。01 的最小视图骨架只是中间交付，不等于整个首页完成。

## 当前交付

01、02、04 已完成；03 导航实现完成但原生键盘等人工验收待补，05 自动化与多数浏览器检查完成。完整命令、体积、尺寸矩阵、工作台往返和未执行项见 FS-0006 §11。首页导航交付不代表各业务模块或完整 PWA 上线。
