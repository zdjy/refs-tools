# FS-0018：论坛为主的用户端首页

- 状态：已实现，验证记录见文末。
- 范围：`apps/referee-web` 首页与阅读页返回入口。
- 本规格替代 [FS-0011](0011-portal-motion-and-simulated-forum.md) 的首页编排；阅读页、示例真实性、静态路由及本地工作台边界继续沿用。
- 视觉与工程依据：[共享 UI 规范](../ui/macos_fiba.md)、[编码规约](../agents/coding-standards.md)。

## 1. 目标

用户进入首页即可浏览讨论和切换版块，同时可快速进入学习、备考、工具、资质、组织及赛事。以讨论列表作为主要内容，取消原首页的大幅专题、滚动关键词、全篇索引与长段落式门户编排。

本轮仅调整前端展示及本地筛选，不接入真实论坛 API，不新增发帖、回复、点赞、关注、通知、排行、私有缓存或离线提交。

Figma、Vercel、虎扑完成截图观察；其他参考通过页面结构观察。Framer Community 当前重定向至模板市场，不作为论坛设计依据。以上仅借鉴信息架构，不复制品牌、图片、配色或用户内容。

遵守共享 UI 基线：暖白画布、白色主列表、暖沙工具区、系统字体、细边框、低强度阴影、球场红激活提示。列表使用分隔线组织话题，不为每帖增加单独浮升卡片与入场动效。首页不再触发 Motion 入场或跑马灯；阅读页保留既有动效适配。

## 3. 信息架构与行为

1. 页头：单 H1「裁判社区」、一句介绍、社区说明锚点。
2. 不显示页头「常用功能」组件；工作台、学习与工具等入口继续通过主导航与辅助区提供。
3. 讨论区：全部、判例复盘、执裁手记、记录台协作、新人笔记。1100px 起显示左侧常驻版块导航；较窄视口用「切换版块」按钮打开左侧模态抽屉，不显示横向筛选条。抽屉展示五个纵向选项、当前激活态与论坛建设进展。选择版块后自动关闭，保留搜索与回应展开状态；关闭按钮、遮罩与 Escape 均可关闭。打开时锁定背景滚动、聚焦关闭按钮，Tab/Shift+Tab 留在抽屉内，关闭后焦点回到触发按钮。转为桌面布局时自动关闭并释放滚动锁，焦点转到桌面已选版块。抽屉宽度不超过 320px，最窄屏仍留 48px 遮罩；内容超高时内部滚动，保留安全区。只借鉴用户参考图的侧栏结构，不复制暗色配色或未实现的草稿、消息等功能。
4. 讨论主列表：展示全部 8 则内置帖子，首部持续标明自编示例和未开放的发帖、回复、点赞能力。每帖展示分类、叙事时间、标题、情境摘要、标签、示例角色及回应数量。关联文章的标题进入已有正文；短帖标题与回应按钮均可展开/收起示例回应。不显示热榜、浏览量或模拟活跃人数。
5. 搜索：仅搜索当前版块内置帖子的标题、正文与标签；去除首尾空白，多词按空白分词并要求全部匹配，保持原编排顺序。搜索与版块筛选可组合，无匹配时说明原因并提供重置入口。重置恢复全部版块与空查询，不清空已展开回应。
6. 辅助区：场边工具（含可用的 GB 2312）、全部 6 篇案头导读、学习与履职的 6 个入口、社区说明。960px 起为右侧栏，较窄视口排在讨论后；不因切换布局重复渲染同一组可聚焦入口。
7. 本地工作台的设备存储、不自动同步、已加载可离线操作与首次离线不保证可用的说明在工具区持续可见。
8. 阅读页返回文案改为「返回社区首页」。`/forum` 继续展示真实建设状态，稳定路径和导航归属不变。

输入、版块、展开状态仅保存在当前页面实例中。首页不初始化工作台、不读取本地比赛，不新增网络请求、依赖、跨端载荷或存储。帖子计数表示内置示例数量，不表示真实活动或热度。

## 4. 验收标准

- 搜索与四版块组合正确，空白查询展示原列表，无匹配可重置；筛选状态通过 `aria-pressed`、结果 status、回应 `aria-expanded` 表达。
- 8 则讨论与全部 6 篇导读可达，所有其他功能入口解析至现有路由，建设状态准确。
- 320、375、640、768、960、1100、1280、1536、1920px 以及手机横屏无页面级溢出；窄屏抽屉不与底栏争夺层级，横屏内容可以内部滚动。
- 可见链接、按钮、搜索与 summary 至少 44×44 CSS px；支持 Tab、Shift+Tab、Enter/Space、可见焦点与 reduced-motion。移动底栏不遮挡末尾入口。
- 运行相关单测、类型检查、生产构建、样式生成检查，比较产物体积。保持 `.vue` 文件行数和组件/状态/请求分层边界。

- 全仓库低内存单测：68 文件、346 项通过，Node 堆上限 192 MiB，峰值 RSS 180.9 MiB。首页新增组合搜索、多词与正文/标签匹配、空结果、重置、展开状态和实例隔离测试。
- 裁判端 `typecheck`、生产 `build`、`test:styles` 与 `git diff --check` 通过。样式检查替换旧首页布局断言，验证论坛主栏、版块栏与搜索焦点工具类。
- `dist/assets` 逐文件累计（bytes，gzip 使用 Node `gzipSync`）：CSS 37,427 → 36,301，gzip 7,214 → 6,962；JS 646,378 → 634,880，gzip 231,219 → 225,325。无新增依赖或生产服务。
- 首页组件均未超过 230 行，无组件 HTTP、跨页面组件引用、持久化或新主题值；旧首页独占的 8 个展示组件已删除。十条阅读路由及正文保持不变。

### 浏览器（首次首页改版记录，后续抽屉调整见第 6 节）

- 本地 HTTPS 开发入口，Chrome CSS viewport 检查 320、375、640、768、960、1100、1280、1536、1920px 及 844×390 横屏：无页面级横向溢出，可见链接、按钮、输入框及展开后的 summary 均至少 44×44 CSS px。桌面与手机截图确认布局层次、暖沙工具面板及手机紧凑页头。
- 版块筛选与「正面镜头」查询组合得到 1 条讨论；空结果为 0；DOM 点击重置恢复 8 条并清空查询。DOM 点击回应按钮后 `aria-expanded=true`、回应可见。
- 讨论标题进入 `/read/contact-review`，标题正确且 H1 获焦，返回链接文案为「返回社区首页」；浏览器后退返回 8 条讨论。

## 6. 移动侧栏与入口精简验证

- 按用户反馈删除整个 `aria-label="常用功能"` 区块及其独占展示数据，主导航与辅助区不变。五个筛选选项由同一个 `ForumBoardMenu` 在桌面与抽屉复用；隐藏桌面副本不可聚焦。
- 复用已安装 Naive UI `NDrawer` 的模态语义、遮罩、背景滚动锁、Escape 和焦点圈定，无新增依赖。Drawer 背景与阴影通过 `ui-theme.ts` 集中映射现有 token，新增安全区布局仅用 Tailwind。
- 定向单测 3 文件、17 项通过，峰值 RSS 110 MiB；类型检查（生产构建内含）、生产构建、样式检查和 `git diff --check` 通过。增加 Drawer 主题同源断言，移除已删除的快捷入口断言。
- 相对此次调整前，`dist/assets` CSS 36,301 → 36,309 bytes，gzip 6,962 → 6,975；JS 634,880 → 654,226 bytes，gzip 225,325 → 232,657。增长来自现有库抽屉及焦点/滚动交互，仍是静态 SPA，不增加服务、缓存或网络请求。
- Chrome：375px 打开抽屉后聚焦「关闭版块侧栏」；Shift+Tab 到末尾「论坛建设进展」，Tab 回到关闭按钮；Escape 关闭后焦点回触发按钮、背景可滚动。选择「判例复盘」后显示 2 条示例并关闭；输入「正面镜头」后通过抽屉切至「新人笔记」，查询保持、结果为 0、抽屉关闭，组合筛选正确。
