# FS-0024：操作结果与恢复反馈修复

## 范围与依据

本轮排查现有真实业务入口，不把管理端模板演示页或尚未实现的模块当作已交付业务。工程要求只维护在[前端操作反馈规约](../agents/coding-standards/frontend.md#5-操作反馈完整性)，不在本文重复定义。裁判端沿用[共享 UI 基线](../ui/macos_fiba.md)，管理端沿用 FS-0010。

## 缺陷与验收

| 入口 | 缺陷 | 修复后行为 |
| --- | --- | --- |
| 后台用户 | 成功只有页内提示；只读详情也可能执行保存；提交时可切换对象 | 新增/编辑/删除后 toast；只读状态不写入、不报成功；提交互斥并锁定对象 |
| 后台组织 | 录入、审批、冻结与解冻无 toast，详情未关闭时页内结果被遮罩遮挡 | 逐次 toast，使用具体动作文案；详情内保留成功文本；列表刷新失败在弹窗内提示并支持只重试读取 |
| 后台成员 | 邀请、审批、移除与撤销无 toast | 结果使用具体动作文案并逐次 toast；保留弹窗内结果及错误/重试 |
| 后台文件 | 下载授权和删除无 toast，列表刷新失败藏在弹窗后 | 结果 toast 与就近文本；下载明确只是授权/发起，非文件已保存；弹窗内列表刷新错误及重试 |
| 账号设置 | 资料、头像、邮箱与密码结果不醒目；资料冲突重读覆盖输入 | 既有结果新增 toast；无改动用信息提示；版本冲突后更新服务器基线但保留本次输入供核对 |
| 退出登录 | 账号页失败说明不就近，退出成功无明确提示 | 两个退出入口均提示成功；账号页保留失败文本及可重试按钮 |
| 本地工作台 | 创建、删除、清空、重置及重试保存缺少完成反馈，撤销可能在保存失败时仍报完成 | 存储成功后才通知并保留文本；失败保留存储错误及重试/导出；高频记分与计时不逐次 toast |
| 区位码工具 | 复制不支持时静默返回、权限异常未捕获；成功文本远离触发处 | 等待剪贴板确认后 toast；失败显示权限/手动复制说明并可重试；重复触发互斥；内部标签映射为中文 |

写入已成功但读取刷新失败时，同时保留成功事实与陈旧提示，不诱导重复写入。两端状态观察适配捕获同轮清空再赋值，相同文案连续操作仍逐次通知；返回路由不重播旧结果，卸载停止监听。成功状态使用自有 `role="status"` 元素，避免 NAlert 固定的 alert 角色覆盖传入状态语义。

## 验证记录

- 全库快测：81 文件、404 项通过，含通知观察器生命周期/重复通知、复制成功/失败/不支持/互斥、本地持久化失败不报成功、用户只读防写、写入成功但刷新失败和档案冲突保留输入。以 192 MiB V8 heap 上限运行；未测总进程峰值 RSS，不能据此声称低于 300 MB。
- `pnpm typecheck`、管理端 `type-check`、两端生产构建、裁判端 `test:styles`、`git diff --check` 通过。无后端、DTO、授权或迁移变更，不执行数据库集成测试。
- 与任务开始时本地 dist 比较：裁判端 JS 1,078,721 → 1,081,637 B，CSS 41,397 → 41,547 B；管理端 JS 3,507,713 → 3,509,718 B，CSS 57,663 → 57,949 B。均不增加依赖或生产服务。管理端既有 size 脚本报告首屏闭包为 0，不作为首屏证据。
- 浏览器：320px 下区位码页与后台组织页无页面级横向溢出；复制按钮 44px 高，键盘焦点保留。复制权限由当前 Chrome 控制，未完成稳定的真实剪贴板写入复验，成功/拒绝路径由注入替身单测覆盖。
- 浏览器在现有后台页面使用**仅内存的合成结果**验证通知适配，不提交/修改真实组织：一次结果 1 条 toast，相同文案再次结果 2 条 toast；toast 在 320px 视口内宽 272px、通知层 z-index 6000；弹窗内外均存在 status 文本，焦点保持输入。测试后清除合成提示并关闭弹窗。此检查不等于已执行真实 CRUD 浏览器全链路。
- 未执行完整屏幕阅读器、系统 reduced-motion、管理端 Dark、全部页面/所有 CRUD 真实写入浏览器矩阵；沿用既有主题与全局减弱动态基线，不宣称这些检查完成。
