- 状态：首版首页与导航已实施，自动化及部分浏览器验收通过；剩余人工验收见文末记录，不代表各业务模块已上线。
- 适用应用：`apps/referee-web`，不包含管理端首页。
- 任务入口：[首页开发任务](../../.scratch/home-navigation/spec.md)。
- 业务依据：[MVP-001](0001-mvp-scope-and-business-rules.md)、[FS-0002](0002-mvp-platform-feature.md)、[队伍级记录台](0003-team-scorer-console.md)。
- UI 依据：[共享 FIBA UI 规范](../ui/fiba_about_ui_specification.md)、[响应式规格](0005-responsive-layout.md)。
- 工程约束：遵循[统一编码规约](../agents/coding-standards.md)，不在本文重新定义依赖、分层、样式或文件长度规则。

## 1. 目标与范围

### 1.1 首版必须交付

1. 将 `/` 从工作台重定向改为独立首页；保留 `/workbench` 的稳定地址。
2. 提供覆盖现有全部业务方向的模块导航；已实现页面直接进入，未实现页面展示准确的建设状态。
3. 提供可实际使用的工具目录，区分本地工作台和 GB 2312 工具。
4. 提供桌面主导航、移动主导航及存量页面返回首页的路径。
5. 首页静态内容不依赖登录服务成功；导航切换不损坏本地工作台记录和计时状态。
6. 完成路由、状态逻辑、样式生成及独立浏览器验收。

### 1.2 首版明确不做

- 不实现学习、练习、考试、认证、组织、赛事、论坛或 GB 2312 的业务闭环。
- 不新增首页聚合 API、数据库表、跨端 DTO、依赖或生产期服务。
- 不新增 Service Worker、离线预缓存、安装引导或完整 PWA 能力。
- 不展示模拟待办、成绩、赛事、认证徽章、通知数量或用户画像。
- 不建设学习完成率、排行榜、连续学习天数、AI 推荐、私信或支付入口。
- 不修改现有登录成功与注册成功后进入 `/account` 的行为，不增加任意 `returnTo` 跳转。
- 不建设个人中心或管理后台；“我的”暂时进入现有账号与安全页。

## 3. 首页信息架构与固定内容

页面顺序固定为：导航 → 主操作区 → 全部模块 → 使用边界说明。首版不留空的“我的待办”“最近学习”占位区。

### 3.1 主操作区

- H1：`篮球裁判工作与学习入口`。
- 说明：`学习备考、资质认证、赛事履职与场边工具。`。
- 主链接：`进入本地工作台` → `/workbench`。
- 次链接：`浏览学习中心` → `/learning`；附近明确写明 `学习模块建设中`。
- 主链接只做导航，不自动创建会话、启动计时、清空记录或读取工作台存储。
- 主操作区使用紧凑的暖沙金特征背景，不使用占满首屏的大图、轮播或自动播放媒体。

### 3.2 全部模块

分组顺序与组内顺序固定，不按认证级别、角色或使用量排序。

首页及工具目录显示简短、持久可见的说明：

### 4.1 路由表

- 学习入口页必须给出资料说明，以及练习、错题、正式考试、考试历史与成绩的可点击入口，不新增 `/learning/assets` 等无页面的链接。
- 首页、卡片、目录、主导航的目标使用同一导航定义来源；路由仍由静态路由表声明，不能根据用户角色动态注入。
- 一级导航选中状态采用明确元信息映射，不用宽泛字符串包含判断；无归属的模块不错误高亮“首页”。
- 当前页主导航使用 `aria-current="page"`；一级栏目下的子页面使用 `aria-current="location"` 表达栏目归属。
- 子路径直接访问、刷新、浏览器前进后退均须正确展示；文档标题使用页面名称及产品名。

### 4.2 主导航与存量页面

- 一级导航固定：`首页` → `/`、`学习` → `/learning`、`工具` → `/tools`、`社区` → `/forum`、`我的` → `/account`。
- 首页、学习入口、工具目录、建设说明页：小于 `tablet` 显示移动底栏，达到 `tablet` 显示桌面主导航，不同时显示两套可聚焦导航。
- 移动底栏预留底部安全区域及内容 padding，页面末尾说明和操作不能被遮挡。
- 顶部品牌始终返回 `/`；移动端顶部不再重复五个栏目。
- 工作台保留场边独立布局、清空等既有操作，增加真正的首页链接，不增加底栏；“跳到主内容”必须单独存在。
- 登录、注册、账号页继续使用 AuthShell，不强行插入主导航或底栏；品牌回首页，工作台快捷入口保持可达。
- 404 明确提供 `返回首页` 与 `进入本地工作台`，不将未知路径静默重定向。

### 4.3 工具目录与建设说明

工具目录固定两项：

1. `本地比赛工作台`：`可使用 · Beta`，进入 `/workbench`；说明记分、统计、计时、犯规、日志及本地导出。
2. `GB 2312 区位码工具`：`建设中 · Beta 规划`，进入 `/tools/gb2312`；说明汉字双向查询、派生码及批量转换。

建设说明页面必须包含：模块标题、`建设中`、明确的当前不可用说明、后续功能范围摘要、返回首页及相关入口。只有既有 Beta 模块增加 `Beta 规划`。

- 不显示无依据的上线日期，不提供无效的“立即报名”“提交认证”“发布帖子”等业务按钮。
- 不要求先登录才能阅读静态建设说明。
- 业务上线后替换对应路由页面并更新导航状态，不同时保留冲突的旧建设状态。

## 5. 身份状态、隐私与弱网

复用现有 auth store，不为首页建立另一套登录状态或持久化策略。

| auth 状态 | 顶部身份区 | 静态内容及本地工具入口 |
| --- | --- | --- |
| `unknown` / `loading` | `正在确认登录状态…`，不先闪现登录按钮 | 始终可用 |
| `anonymous` | 登录、注册入口；移动端可只保留登录，注册从登录页进入 | 始终可用 |
| `authenticated` | 显示名称与账号入口；长名称可换行，不展示完整邮箱或实名 | 始终可用 |
| `error` | `暂时无法确认登录状态` 与重试，不能伪装成未登录 | 始终可用 |

- 首次需要身份投影时调用既有 `restore()`；重试调用 `restore(true)`，不新增轮询或每次路由切换强制刷新。
- 不因恢复会话失败整页显示错误或锁住工作台；重试过程中只更新身份区。
- `/account`、`/login`、`/register` 保留既有状态处理与登录后跳转。
- 首版无角色专属管理入口，不请求角色矩阵，不把认证级别映射为权限。
- 后续真实模块仍按 MVP-001 执行登录、邮箱验证和 API 对象级授权；静态说明页开放不等于业务资源公开。
- 不新增首页私有数据缓存、签名 URL 缓存或离线业务提交队列，不以 `navigator.onLine` 判断服务端请求一定成功。

## 6. 工作台导航安全性：必须先处理的集成门槛

当前 `initialize()` 每次执行 `restore()`。新增首页后，用户将频繁离开并返回工作台，必须验证并按需修正以下行为：

1. 同一应用生命周期内，首次进入工作台才读取本地快照；已成功初始化后的返回不自动重新读取覆盖内存状态。首次读取失败时仍保留明确的重试读取路径。
2. 保存失败后的内存比分、日志、会话及错误提示，离开到首页再返回后仍存在；用户可重试保存或导出，不能把旧快照当成最新状态。
3. 离开页面不隐式暂停、重置或新建比赛；运行中的时钟按既有时间戳语义继续，返回时重新结算，到时不重复写提示事件。
4. 初始化、返回及重试不叠加 interval、事件监听器或下载资源；应用销毁仍正常释放。
5. 首页和工具目录不得实例化工作台 store、调用其初始化或遍历本地快照来显示“最近比赛”。
6. 不更改存储键、历史规则版本、规则快照、导出协议或本地会话不自动同步的边界。
7. 浏览器整页刷新仍受现有持久化能力约束：保存失败的内存内容不保证跨刷新保留，提示用户先重试或导出，不宣称修复了这一限制。

此处只处理新增导航触发的状态恢复风险，不顺带重构全部工作台领域模型。保持现有 store 生命周期方案即可；若更改状态所有权或持久化协议，须另行记录 ADR。

## 7. UI 布局与可访问性

视觉和工程 token 直接引用共享规范，不建立第二套首页设计系统。首页属于工具入口，采用适度密度，不机械使用营销页超大纵向留白；此为对共享示例布局的任务适配，不放宽颜色、形状及交互要求。

- 每个模块分组：基础单列，`compact` 起双列，`xl` 起最多三列；不足三张不填充假卡片。
- 主操作区基础纵向，`tablet` 起可采用介绍与快捷操作双列；最大内容宽度 1280px，超宽屏居中。
- 页面只有一个 H1，分组使用 H2，模块名称使用 H3；提供 main、nav 及跳到主内容入口。
- 卡片整块链接不得内嵌其他按钮或链接；图标使用已有方案或轻量内联 SVG，装饰图标对辅助技术隐藏，不使用 emoji 代替产品图标。
- 触控目标、焦点、对比度、按压反馈及 reduced-motion 按共享规范实际验收；状态不能只用颜色表达。
- 路由切换后使新页面主标题或 main 获得合理焦点，避免焦点丢到 body；通过表现层或导航适配实现，不让业务状态依赖 Router。
- 移动导航切换和浏览器返回不清空业务状态；不承诺返回原滚动位置，延续现有路由回到顶部行为。
