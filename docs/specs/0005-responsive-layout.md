# 前端响应式尺寸细分

## 范围与动机

覆盖现有裁判端工作台、登录/注册与账号管理页面。不新增管理端、跨端契约、业务规则或同步行为；沿用[共享 FIBA UI 规范](../ui/fiba_about_ui_specification.md)，工程断点唯一维护在[样式规约](../agents/coding-standards/styles.md#3-token-与响应式配置)。

原布局在 480px 就将球队面板分为双列，单卡宽度约 210px；768px 同时启用工作台侧栏和认证双栏，导致内容突然收窄；1100px 又将记分牌切为三栏，按钮容易多次折行。不能仅以页面没有横向滚动判定适配成功。

保留既有断点值，补充大手机横屏/小平板、平板横屏、小桌面和宽桌面的过渡档。断点按 CSS viewport 宽度判断，不按设备型号、DPR 或 UA 判断。

## 用户可见行为

- 窄屏手机：球队、计时卡片纵向排列；最窄尺寸的技术统计操作使用单列，常规手机渐进为双列。不缩小按钮或字号来塞入多栏。
- 宽手机：计时区先变为双列，比赛钟独占一行；球队仍单列，避免刚过宽手机阈值就压窄比分操作。
- 大手机横屏/小平板：球队双列、技术统计三列；到标准平板宽度后，三个时钟并排，比赛钟不再跨列。
- 平板横屏：工作台会话列表才变为侧栏；登录/账号页才启用介绍区与表单双栏。较窄平板保持上下布局，表单维持可读宽度。
- 小桌面：保留球队双列及横向计时区，不因启用侧栏提前压成三栏。
- 标准桌面：记分牌变为主队、中央纵向计时、客队三栏，技术统计四列。
- 宽桌面：工作台最大内容宽度适度增加，技术统计五列；超宽屏居中限宽，不无限拉伸。
- 弹窗字段和球队统计延后启用双列；短横屏使用 `dvh` 限高和弹窗内部滚动，确认/关闭入口可达。
- 长队名、统计数字、规则标识与状态文案允许折行；会话横向列表仅在自身区域滚动，不以隐藏页面溢出掩盖内容。

## 验收标准

1. 320、360、375、390、414、430、480、600、640、768、820、960、1024、1100、1280、1440、1536、1920px 均无页面级横向溢出。对每个工程断点验证前 1px、恰好命中与后 1px 的布局。
2. 在 640px 前球队单列，在 960px 前无工作台侧栏/认证双栏，在 1280px 前记分牌不启用三栏；三时钟横排区间与中央纵排区间无遗留跨列造成的隐式空列。
3. 登录/注册、空工作台、已有比赛、长队名、校时展开、新建和统计弹窗均可用；弹窗在 667×375、844×390 横屏下不超出可视高度，内容可滚动到操作区。
4. 控件维持至少 44×44 CSS px、可访问名称、可见键盘焦点；弹窗 Escape、焦点恢复、禁用/错误状态和 reduced-motion 不回归。
5. 单测、类型检查、生产构建及独立样式生成检查通过；样式检查覆盖全部集中断点、顺序与真实布局工具类，确认不存在默认主题断点意外进入产物。

## 验证记录

- 使用生产静态预览在 Chrome 中检查工作台（含 40 字符中英文混合长队名）、登录、注册及未登录账号页；每页覆盖 36 个请求宽度，包含常用手机、平板、桌面及全部断点附近尺寸，未发现页面级横向溢出。实际检查以 `clientWidth` 为可用宽度，避免把桌面滚动条占位漏算。
- 验证记分牌单/双/三栏、计时区单/双/三列及桌面中央纵排、认证双栏的切换符合规格；侧栏长会话名不侵入主内容，按钮允许随内容增高。
- 发现并移除 `body` 固定最小宽度：320px 桌面 viewport 出现垂直滚动条后，可用内容不足 320px，原声明会造成横向滚动。不使用页面 `overflow-x: hidden` 掩盖问题。
- 新建与统计弹窗分别覆盖 320×568、375×812、480×800、640×800、667×375、844×390、960×720、1280×800；限高生效，滚动到底部后确认/关闭入口可见。Escape 关闭后焦点分别恢复到新建与技术统计按钮。
- 320px 校时展开、默认禁用进攻钟、44×44px 操作尺寸、可见焦点及 reduced-motion 已检查；768px 注册页及 1024px 长队名记分牌另做视觉检查。
- 前端 12 个测试文件、47 项测试通过；192 MiB V8 heap 上限下，进程峰值 RSS 112.5 MiB。全仓库 `pnpm typecheck`、前端生产构建、独立 `test:styles` 及本次文件 `git diff --check` 通过。
- 主 CSS 由 15.87 kB（gzip 3.79 kB）变为 17.00 kB（gzip 3.93 kB）；工作台 chunk 由 94.83 kB 变为 95.27 kB，认证共享 chunk 由 7.66 kB 变为 7.79 kB。未新增依赖或生产运行时服务。
- 限制：以上为 Chrome CSS viewport 模拟，不等同于 iOS/Android 真机、虚拟键盘或 Safari 验收；未连接真实账号测试已登录安全设置，未重新穷举网络加载/服务端失败状态。此任务未修改 API、领域状态或错误处理逻辑。
