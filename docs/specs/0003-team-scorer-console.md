# 队伍级记录台

- 状态：已实现，浏览器验收见本次交付说明
- 来源：`code_artifact.html` 功能参考；不采用其中的视觉样式或球员模型。
- 继承：[MVP-001 §9](0001-mvp-scope-and-business-rules.md)、[FS-0002 §4.6](0002-mvp-platform-feature.md#46-离线工具)。本规格替代此前工作台“仅计时和犯规、不含声音”的阶段性范围。

## 功能边界

1. 仅记录主客队：可编辑队名，记录罚球/两分/三分命中与不中、篮板、助攻、抢断、盖帽、失误、技术犯规。无球员名单、号码、位置、换人或个人犯满逻辑。
2. 命中同步累计比分与分节比分；投篮命中率按队伍汇总。比分纠错只调整本节比分，不伪造投篮数据，技术统计误录通过撤销更正。本节比分与球队犯规不得小于零。
3. 球队犯规阈值仅作文字提示，不自动宣判罚球；技术犯规独立统计，不自动加计球队犯规或判罚。
4. 交替拥有箭头初始未设置，支持手动指向、争球后切换。箭头不是实际控球判断。
5. 比赛钟默认联动进攻钟，可切换独立模式；快捷秒数取原会话配置，保留 8 秒手动提示。停表可精确校正至 0.1 秒。后台恢复基于时间戳，到时停止相关时钟并记录提示，不自动裁定违例。
6. 球队暂停消耗一次本节额度、停止比赛与进攻计时并启动暂停倒计时，可提前结束、恢复误扣额度。结束后不自动恢复比赛。暂停中不得再次请求暂停或启动比赛/进攻钟。
7. 新建时可配置常规节数、每节/加时时长、进攻/短进攻秒数、暂停时长、每节暂停配额和犯规提示阈值。配额明确为本工具的“按节”模型，不声称完整复现 FIBA/NBA 规则。新建弹窗提供三个“参数预填”（4×10 分钟·24 秒、4×12 分钟·24 秒、2×20 分钟·30 秒），只预填节数、每节分钟与进攻钟秒数，创建后与手填无区别，名称只描述时长，不是赛事规则集；常用三项直接展示，其余参数折叠在“高级参数”，内容区独立滚动、“创建比赛”固定在底部。
8. 下一节需要确认，常规节次结束后进入加时而不是循环到首节；换节清本节犯规、按配置补足本节暂停、重置时钟，保留总分和技术统计。加时也按同一配额及犯规清零模型处理，不推断特定竞赛规则。
9. 撤销保留每会话最近 40 次手动动作的内存快照；切换会话隔离历史，刷新后清除历史。撤销恢复当时的时钟剩余值但保持停表，需核对后手动恢复；整场重置需要确认，清除比分、统计、犯规、暂停、节次和日志，保留队名与规则；可撤销。删除与清空会话不可撤销，必须确认。
10. 事件流水保留最近 200 条，含节次、比赛时间、比分与操作信息；可导出流水 CSV、球队统计 CSV，以及完整会话 JSON。CSV 转义公式前缀和引号，不把队名解释成公式；文件仅本机生成。
11. 手动哨音、蜂鸣器与计时到零提示音由用户显式启用，默认静音。音频失败不影响比赛状态，并展示可见降级提示；系统级锁屏不承诺后台声音。键盘快捷键仅在开启快捷键后生效，输入控件、弹窗和组合键编辑不被劫持。

## 本地数据与离线

- 延续 ADR 0008 的本地存储边界，不新增 API、同步或服务端比赛记录。应用外壳由 [ADR 0031](../decisions/0031-offline-app-shell-service-worker.md) 的 Service Worker 预缓存，首次联网访问后可离线冷启动工作台；从未联网加载过的设备仍不能离线打开。比赛数据仍只存本机，不进入 Service Worker 缓存。
- 沿用 v1 存储键，仅在读取旧会话时补齐空队伍记录，旧比分无法推断，按零初始化；不写回读取结果，不更改旧规则版本。新会话冻结新增参数；损坏的新结构拒绝读取，保留原始数据供重试/备份。
- 保存失败保留内存记录并允许重试/导出；恢复失败阻止覆盖旧数据，并提供“导出原始数据”：原样下载存储中的字符串，不解析、不改动存储，存储为空时如实提示无可导出记录；导出提示比赛数据的共享设备风险。不存球员或认证数据。

## UI 与验收

遵循[共享 UI 规范](../ui/macos_fiba.md)，保持暖沙金、白色卡片、炭黑与球场红、胶囊按钮，延续 FS-0002 对场边操作密度及可读性的窄范围例外。禁止暗色 LED、霓虹、渐变、任意球队颜色和外部字体/CDN 依赖。

- 手机（< 960px）上滚动记录时，顶部吸顶记分条持续显示双方比分、比赛钟（点按启停）和进攻钟（点按重置为规则集进攻秒数）。两队卡片在 375px 起并排，320px 单列；改队名、比分纠错、恢复暂停收进“队伍修正”，声音、快捷键、会话 JSON、重置整场、删除比赛收进“更多操作”，“清空本设备全部比赛”位于侧栏共享设备提示处，不与记分按钮并排。
- 320px 移动端无页面横向溢出，队伍操作不依赖 hover，触控目标至少 44×44px。
- 表单字段有可访问名称，错误有持久文本反馈；弹窗支持 Escape 与焦点恢复，破坏性动作确认；计时数字不高频 live 播报，到时有文字反馈。
- 领域测试覆盖计分/纠错、统计、暂停配额、球权、换节/加时、联动及后台到时；应用测试覆盖撤销隔离、存储失败；持久化测试覆盖旧会话兼容与损坏数据拒绝。
