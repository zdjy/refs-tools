# FS-0009：管理端登录页中性配色

## 范围与要求

管理端 `/login` 使用[共享 FIBA UI 规范](../ui/fiba_about_ui_specification.md)中的暖白、浅沙、白色与炭黑。按用户要求，登录页为不使用篮球场红的窄范围例外：品牌区采用浅沙纯色，主按钮、链接、复选框、输入框聚焦及字段错误反馈采用中性色。深色模式使用暖黑表面与浅沙色交互。错误保留明确的字段文案，不只通过颜色表达。

主题在 `apps/admin-web/src/settings/colorTheme.ts` 集中维护，由根 Provider 按登录路由选择；离开登录页后恢复管理端既有主题。登录提交与导航行为保持现状。

## 验收标准

- 品牌背景无红色或渐变；默认、悬停、聚焦、选中、加载及字段错误状态不引用红色强调色。
- 浅色与深色模式的文字、控件和错误文案保持可读，链接具有可见键盘焦点。
- 320px 宽度无页面级横向溢出；大尺寸输入框、登录按钮及第三方登录入口至少为 44px 高。
- 执行管理端类型检查与生产构建，并在浏览器检查桌面、窄屏及空表单校验。

## 既有工程差异

管理端目前使用上游模板的 Tailwind 3、配置文件与全局 important，与仓库现行 Tailwind 4 样式规约存在差异。本次限定为登录页配色修改，不升级依赖；登录页使用现有构建链的工具类与集中主题，960px 使用命名 `tablet` 断点，未新增 important 或组件内部选择器覆盖。该差异仍待独立迁移处理。
