# 存量界面 Tailwind 迁移

- 状态：已完成
- 决策依据：[ADR 0013](../decisions/0013-tailwindcss-styling.md)

## 范围与不变项

迁移 `apps/referee-web` 的导航、应用骨架、404、登录、注册、账号和队伍级记录台及私有子组件。仅替换样式实现，不改变文案、业务规则、数据契约、登录会话、本地存储、路由或离线边界。

视觉继续遵循[共享 UI 规范](../ui/macos_fiba.md)，工程约束仅维护于[样式规约](../agents/coding-standards/styles.md)。迁移当时保持原有视觉；该基线已由 [FS-0012](0012-macos-vibrancy-ui.md) 切换到新规范，圆角、阴影与动效取值以新规范和样式规约为准；延续既有场边操作密度例外，不套用营销页留白。

## 验收标准

1. 自有 DOM 的布局、排版和状态迁移为静态可扫描的 Tailwind 类，删除对应旧声明及失效导入。
2. 保留全局 reset、触控、焦点、reduced-motion 基线；不启用 Preflight，不增加依赖或生产服务。
3. Naive UI 内部样式通过公开 props、slots 和集中主题处理，不使用 important、内部选择器或深层覆盖。
4. 320px 与四档断点边界及桌面无新增页面级横向溢出；长队名、错误、空状态、弹窗和加载状态可用。
5. 触控目标至少 44×44px；可访问名称、键盘操作、焦点恢复、错误提示及 reduced-motion 不退化。
6. 对照迁移前截图和关键计算样式检查视觉差异，说明必要 CSS 例外及既有问题，不把构建通过当作视觉验收。
7. 相关单测、类型检查、生产构建和工具类生成检查通过，并记录产物体积变化。

## 验证记录

迁移前后浏览器证据及产物测量放在本地 `.cache/tailwind-migration/`，不提交账号数据或临时截图。

### 实施结果

- 删除 `styles/layout.css`、`styles/utilities.css`、`views/workbench/workbench.css` 及其导入，移除 404 页 scoped 样式；`auth.css` 仅保留带说明的品牌折面 `clip-path`。
- 保留 `base.css` 的全局基线；默认值进入 `base` 层，按压、焦点及 reduced-motion 保持未分层，防止组件库屏蔽这些状态。
- Naive UI 尺寸差异集中通过 `ui-theme.ts` 的公开主题适配维护；Modal preset 根宽度使用公开 `style` 属性保留视口留白，未引入内部选择器或 important 补丁。
- UI token、四档断点、Naive UI 全局主题及业务状态/API 均未改变；Vue 文件最长 132 行。

### 检查结果

- 前端 12 个测试文件、47 项测试通过，包含新增的 token/主题适配测试；以 192 MiB V8 heap 上限运行，进程峰值 RSS 约 123 MiB。
- 全仓库 `pnpm typecheck`、前端生产构建、`test:styles` 均通过；生产静态预览在 320、1440px 验证了会话恢复、响应式记分牌、画布颜色与主要按钮尺寸，无页面横向溢出。独立构建检查验证 token、四档断点、状态变体及任意值，并排除默认调色板、Preflight 和扫描范围外规则。
- 对工作台、登录、注册、账号、404 页面在 320、374、375、479、480、767、768、1099、1100、1440px 检查布局和计算样式，无页面级横向溢出；320、768、1440px 的 15 张标准截图逐像素一致。
- 另对 13 类场景在 320、1440px 比较迁移前后共 52 份记录：空数据、恢复失败、创建弹窗、统计弹窗、长队名、计时到零、首次/修改密码、字段错误、认证加载与服务失败。20/26 对截图逐像素一致，剩余存在少量抗锯齿像素差异，未发现布局或主题回归；可见文案节点的字号、行高、间距和颜色一致。
- 主要按钮、输入框和折叠操作目标均至少 44×44px；键盘 Space 可打开统计弹窗，Shift+Tab 焦点保持在弹窗内，Escape 关闭后恢复到触发按钮，键盘焦点清晰可见。
- 通过浏览器媒体仿真核验 `prefers-reduced-motion: reduce`，组件库按钮过渡和动画时长降至 0.01ms，结束后恢复媒体配置。
- 账号状态使用临时本地服务器的合成响应，不操作真实账户，不替代认证服务集成测试。本次未改后端、数据库或跨端契约，相关数据库/授权检查不适用；未进行 Safari/Firefox 真机回归，不新增跨浏览器兼容性承诺。
