# FS-0011：内容门户的动效与模拟论坛

- 状态：已实现；自动化与 Chrome 无头浏览器验收通过，人工项见第 5 节。
- 范围：裁判端首页与十条阅读路由。
- 决策：[ADR 0019](../decisions/0019-motion-and-simulated-forum-content.md)。
- 视觉基线：[共享 FIBA UI 规范](../ui/fiba_about_ui_specification.md)，不变。
- 对 [FS-0008](0008-editorial-home.md) 的关系：仅在第 1 节列出的三点上放宽，其余（路由、工作台生命周期、无新增 API、无持久缓存）继续有效。

## 1. 相对 FS-0008 的例外

| FS-0008 原约束 | 本规格 |
| --- | --- |
| 禁止视差、持续自动播放 | 允许滚动联动（入场、阅读进度、插图轻微位移）和关键词跑马灯；跑马灯必须有暂停按钮；reduced-motion 下全部关闭 |
| 禁止虚构作者、头像、热度、回复数 | 允许示例角色、叙事性时间和固定示例值，每处标注“示例”；仍禁止真实姓名、头像图片、真实时间戳、浏览量、排名 |
| 讨论仅两篇 | 导读 6 篇、讨论示例 4 篇，另有 8 则首页信息流帖子 |

## 2. 首页结构

1. Hero：大字标题、摘要、双主操作、原创球场示意。
2. 关键词带：8 个主题词水平滚动，带暂停按钮。
3. 内容索引：10 篇文章编号列表；960px 起悬停或聚焦时右侧切换封面预览。
4. 导读横轨：5 篇导读的封面、摘要和三节目录。
5. 社区讨论示例：版块筛选（全部与 4 个版块）、帖子卡、可折叠的示例回应。
6. 案头词汇：6 个自编术语。
7. 赛前核对清单、收尾面板、全部功能目录、本地工作台边界说明（保留）。

## 3. 阅读页

大字头图与封面、阅读时长估算（按 500 字每分钟，仅为参考）、顶部阅读进度条、目录当前节高亮（`aria-current`）、讨论示例的示例回应区、同类型“接着读”及相关文章。

## 4. 内容真实性约束

- 人物只有角色称谓，且以“示例角色”结尾；头像为几何图形。
- 时间为“训练回放复盘课之后”类叙事描述，不含日期或时钟。
- “觉得有用”为固定示例值，不可交互；发帖、回复、点赞均未开放，页面持续说明。
- 导读只提供方法，不给规则集无关的统一罚则，沿用 FS-0008 的版本核对声明。
- 以上由 `home-presentation.test.ts` 对字段集合、角色名后缀与时间格式做断言。

## 5. 验证记录

### 自动化

- 全仓库低内存单测 34 文件、192 项通过（Node 堆上限 192 MiB）；裁判端 `typecheck`、生产 `build`、`test:styles` 通过。
- `test:styles` 断言更新为新布局实际使用的主次栏、版块侧栏、阅读侧栏、进度条与悬停抬升工具类；移除不再使用的旧类。
- 源码扫描：新增目录内无渐变、`shadow-2xl`、`!important`、`:deep`、十六进制或 rgb 硬编码色值（唯一例外是规范给出的悬停暖调阴影）；所有 Vue 文件不超过 230 行。
- 体积（`dist/assets` 逐文件累计，构建前后）：CSS 28,403 → 33,323 bytes（gzip 5,953 → 6,843）；JS 507,990 → 617,112 bytes（gzip 176,738 → 217,972）。首页 chunk 28.8 kB，阅读页 10.5 kB。JS 增量含 `motion` 与新增文章正文，主入口 chunk 基本不变（68.77 kB）。

### Chrome 无头浏览器

- 首页、观察位置导读、接触复盘讨论共 3 页，在 320、375、480、640、768、960、1100、1280、1536、1920px 下检查：无页面级横向溢出、每页一个 H1、可见的链接与按钮均不小于 44×44 CSS px、无无名称的链接或按钮、可见文本不含 emoji。最终一轮 30 个组合全部通过。
- 验证中发现 320px 下论坛版块栏因 grid 子项缺少 `min-w-0` 撑出 8px 横向溢出，已修复并重跑通过。标题在 375px 起单行，320px 下降一档字号。
- 滚动一遍后，主内容内不透明度为 0 的元素从 34 个降为 0，入场动画不会遗留隐藏内容。
- 系统 reduced-motion 模拟：入场不隐藏任何元素，跑马灯不渲染、无动画变换、无暂停按钮。
- 版块筛选切换后 `aria-pressed` 与 status 数量更新；示例回应展开后 `aria-expanded` 为 true；阅读页按正文区计算进度：规则版本导读在滚动 0%、15%、30%、50%、75%、100% 处进度依次为 0、0、0、0.75、1、1（头图与正文开始前为 0），目录高亮在第 3 节处切换到“用情境组织自己的笔记”。

### 未执行与限制

- 真实键盘（Tab/Shift+Tab、Enter/Space）的逐项操作、屏幕阅读器、Safari 与 Firefox、iOS/Android 真机、最大系统字号均未验收。筛选与展开使用的是 DOM 点击，不等同于键盘验收。
- 动效的帧率与低端设备表现未测量。
- 进度条的 `scroll-timeline` 采用 `motion` 的 JS 实现，未测量在长页上的主线程占用。

## 6. 编码规约自检

后端项（1–4、7–9）不适用。Vue 行数、组件无 HTTP、Naive UI 边界、状态分层（版块与展开仅为页面局部 `ref`，无 store 与持久化）、Router 边界（路由由注册表生成但仍为显式静态路径）、注释、Tailwind 与 token 均已检查通过。新增的 `components/ui/motion/` 不引用业务模块。浏览器人工项见上节。
