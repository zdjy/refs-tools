# FS-0026：管理端界面精修

- 状态：已实施，验证记录见 §5。
- 适用应用：`apps/admin-web`。无后端、DTO、授权或迁移变更。
- 依据：[FS-0010](0010-admin-color-theme.md)（配色与组件映射，本规格不改动）、[FS-0009](0009-admin-login-colors.md)（登录页中性配色）。

## 1. 目标与非目标

目标：去除模板遗留内容，修复登录后落到错误页，对齐业务页筛选区，补齐顶栏可访问性并消除窄屏溢出。

非目标：不改 FS-0010 的 token、不改后端权限；菜单权限页和角色权限页仍是 Mock 数据，不在本次范围。

## 2. 用户可见行为

| 项 | 行为 |
| --- | --- |
| 登录后落点 | 默认进入 `/system/user`。原 `/dashboard` 需要 `dashboard_console` 权限，而会话权限为空，导致落到错误页。 |
| 路由范围 | 仅注册 `router/modules/system.ts`。仪表盘、表单、列表、异常、结果、组件示例、设置、关于等模板模块不再注册，侧边栏由 17 项减为 6 项。 |
| 标签页 | 从本地存储恢复标签时丢弃已不存在的路由。用户管理为固定标签。 |
| 头像菜单 | 移除指向模板「个人设置」页的入口，仅保留退出登录。 |
| 登录页 | 删除技术栈介绍、记住我、忘记密码、第三方登录和注册入口。保留 FS-0009 的中性配色，并说明账号由平台管理员授权。 |
| 筛选区 | 输入框与下拉框统一为 44px 高，标签与控件底部对齐，主操作按钮靠右。组织、用户、文件三页一致。 |
| 文件页 | 补充 `avatar`（头像）用途选项；所属用户 ID 列收窄并以悬浮提示显示全文，创建时间列不再被固定操作列遮挡。 |
| 顶栏 | 折叠、刷新、锁屏、全屏、语言、账号、项目配置均为 `button`，带可访问名称与可见焦点，最小宽度 44px。语言和账号菜单改为点击触发。 |
| 顶栏头像 | 用会话里的 `avatarMediaId` 调 `GET /media/:id/read-url` 换取短期地址（本人读授权，不走要求理由并写审计的 `/admin/media`）。签名只存内存，退出登录时清空；无头像或签名失败时显示显示名首字符。 |
| 404 页 | 去掉冷蓝插图，改为文字版：主色 `404`、「页面不存在」、被访问的路径，以及「回到首页」「返回上一页」（无历史时退回首页）。标签与面包屑标题统一为「页面不存在」，不再重复显示。 |
| 窄屏 | 小于 640px 时隐藏面包屑、锁屏、全屏和用户名，390px 下顶栏不再溢出。 |

## 3. 边界情况

- 代码层面 `views/` 下的模板演示页文件仍保留，只是不再注册路由，后续可单独清理。
- 账号菜单触发方式由悬停改为点击，以便键盘和触屏使用。

## 4. 已知未处理

- 菜单权限页、角色权限页是明确标注的 Mock 数据。
- 项目配置抽屉仍提供导航模式和动画类型选项，与 FS-0010 §3 的收敛要求不一致。
- 403、500 页仍使用冷蓝插图，但路由未注册，当前访问不到。
- 锁屏页头像仍是通用图标。
- 用户页对本人账号置灰「编辑」按钮时没有原因说明。

## 5. 验证记录

- `vue-tsc --noEmit` 无错误；`vite build` 通过；`vitest run apps/admin-web` 14 个文件 70 个测试通过（头像改动后重跑）。
- `impeccable detect` 对登录页、系统页、顶栏、标签栏和异常页无发现。
- 浏览器（1627px，浅色）：登录成功后进入用户管理；侧边栏 6 项、标签 5 个；文件页筛选控件均为 44px，表头列不重叠；顶栏 7 个按钮均有名称。
- 浏览器（390px，浅色，用户页）：无横向溢出，顶栏按钮均在视口内。
- 头像：浏览器中一次完整加载只发 1 次 `read-url`，图片加载成功（240px 宽）；新增 `avatar-state.test.ts` 5 个用例，管理端共 14 个文件 70 个测试通过。
- 404 页（1627px，浅色）：主色、路径底色、按钮 44px 高均与 FS-0010 取值一致，页面无溢出，控制台无报错。
- 深色主题只核对了用户页的 `canvas`、`primary`、侧边栏和卡片背景，与 FS-0010 取值一致；未逐页检查。
- 头像无图回落、404 页的深色主题与 390px 表现、「返回上一页」有历史时的行为均未在浏览器验证。
- 未在 390px 下检查组织页和文件页，未检查键盘 Tab 顺序，未做 reduced-motion 验证。
