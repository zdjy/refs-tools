# FS-0017：管理端文件管理

- 状态：首期实现完成；浏览器原生键盘与 reduced-motion、真实云存储验收限制见下文。
- 范围：管理端 `/system/file`、API `/api/v1/admin/media`。
- 决策：[ADR 0027](../decisions/0027-admin-media-governance.md)。媒体直传与状态继续遵守 [FS-0014](0014-media-control-plane.md)。

## 行为与验收标准

1. 已验证且有效的平台管理员通过独立 `media.manage` 权限管理全平台媒体元数据；组织角色、内容编辑及普通用户不能访问此入口 API。每次请求实时授权，不以菜单或前端角色判断作为安全边界。
2. 每页 20 条，按创建时间、ID 倒序分页；支持原文件名、归属账号昵称/实名、用途、状态筛选。归属账号只接受昵称或实名关键词，不接受用户 UUID 或 ID 片段：管理员按人定位文件，账号标识只用于展示（列表显示昵称 + UUID 尾号，详情另列完整 UUID）。搜索按字面匹配，分页上限 10000。列表和详情仅返回文件名、ID、owner、归属账号昵称、用途、目标、类型、声明/核验字节数、创建/到期/核验/删除/清理时间，不返回 object key、ETag、凭据或存储 URL；实名只参与匹配，不进入任何响应或审计快照。查询和详情访问均审计。
3. 管理员可对 available 文件填写理由并申请 60 秒下载授权；下载强制 attachment/no-store，不内联预览未知内容。签名在事务外生成，返回前重新检查账号、权限和状态并原子写审计。平台治理授权不表示平台角色继承组织运营权限。认证原件的下载由 [FS-0030](0030-certification-api.md) 收窄为认证申请/申诉专用范围入口；本治理页保留其元数据，通用下载返回 `CERTIFICATION_ACCESS_REQUIRED`。
4. 删除填写理由并二次确认。服务端先逻辑删除并同事务审计，随后事务外删除对象；失败保持不可读，明确提示可能已撤销访问，允许重试。已删除对象重试仍需实时授权并记录本次操作。available 的认证/答卷/赛后证据禁止通用删除，不能以管理员身份绕过留存审批。
5. 原文件字节不经过 API。不增加任意文件上传、无用途文件仓库、桶浏览、公开链接、批量删除、在线预览、媒体编辑或转码。新上传继续通过具体业务的直传入口，避免凭管理角色伪造业务用途；本页说明这一边界。
6. 管理端使用 [FS-0010](0010-admin-color-theme.md) 的主题和现有 Tailwind 3 工程基线，不在本任务迁移工具链。窄屏表格局部滚动、弹窗适应视口，操作按钮至少 44px 高；明确加载、空列表、错误、陈旧/离线、重试与成功。理由在失败后保留，关闭后清除；旧详情/列表响应不能覆盖新选择，不缓存私有记录和签名 URL。

## 交付自检（workflow）

1. SQL 仅在管理只读 Repository；Service/routes 无 SQL。
2. Repository/事务端口无驱动类型，装配入口注入。
3. 授权、状态变更和审计共用连接；存储 IO 在事务外；审计失败回滚有真实测试；既有事务适配未修改。
4. 媒体表仍归 media，参数化最小投影，不改约束/迁移；复用既有账号/媒体/角色锁，已执行相关 PostgreSQL 检查。
5. 两个 Vue 文件分别 76/37 行，均低于 230 行。
6. Vue 无内联 HTTP，所有请求经管理媒体网关。
7. 复用既有禁缓存/合并的 alova 传输客户端；上下文错误翻译不泄漏 URL；下载交给浏览器，不缓存签名。
8. 新载荷、查询和响应均在 contracts/admin-media。
9. 新 Service 有配套测试；无新增核心 domain 规则，权限词汇由授权矩阵覆盖。
10. media.manage 仅固定单点策略，实时角色读取；测试全角色矩阵、签名期间撤权/删除及审计失败。
11. Naive UI 只在视图及 presentation。
12. 子组件归文件模块，无跨页面/应用引用或无需求通用封装。
13. 复用管理端集中 Light/Dark token；无页面新色值或私有样式覆盖。
14. 理由、确认、离线、失败保留输入、重试和未确认结果反馈均已实现；API 独立执行授权/留存。
15. 页面局部内存状态，无新增 Pinia 或持久化。
16. Router 仅增加静态导航，无前端权威授权。
17. 移动尺寸、名称、主题、相关测试/类型/构建通过；原生键盘、reduced-motion 和辅助技术限制如上，不标通过。
18. 中文注释解释两阶段授权、撤销顺序和 SQL 字面搜索，无死代码或无 issue TODO。
19. 字节、时间及分页边界在契约/展示函数与规格明确，未涉及篮球规则集。
20. 新页使用管理端现有 Tailwind 3 基线（FS-0010 已允许该迁移例外），不增加 CSS 或工具链。
21. 自有元素消费管理端语义 token，Naive UI 走公开 props；未新增 important/深层覆盖。既有 Tailwind important 配置未修改。
