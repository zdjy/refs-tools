# 场边 UI 基线（Courtside）

裁判端（`apps/referee-web`）的版式、材质与动效基线。**配色以 [macOS 毛玻璃 · FIBA 暖沙金](./macos_fiba.md) 为唯一来源**，本文不重复色值表，只记录取用规则与差异；版式参考 Apple iOS：分组容器、大标题、胶囊选中态、弹性曲线。取舍原因见 [ADR 0033](../decisions/0033-courtside-ui-baseline.md)，工程映射见[样式规约](../agents/coding-standards/styles.md)。管理端不受本文约束。

## 1. 方向

* **平铺**：内容直接铺在暖沙画布上，用 1px 细线分段，不把每一块都装进白色圆角卡片。圆角卡片只留给浮层、输入类控件和登录面板这类需要承载阅读的单块区域。
* **大标题**：页面标题 32/40px 粗体、紧字距，下方一句说明，无分隔线与底色横幅。
* **列表行**：入口与讨论用平铺列表行，上下各一条细线，行间缩进细线，右侧 chevron 表示可进入；行悬停用半透明白底，背景动效仍可透出。
* **平面**：不使用渐变（含色晕、高光层、渐变投影）。质感来自细线节奏、毛玻璃导航、背景线稿动效与交互动效。
* **直述**：文案直说状态与下一步，不用口号式标题，不编造数据。

## 2. 颜色取用

色值见 `macos_fiba.md` §2，工程唯一来源 `src/ui-tokens.ts`，`ui-theme.test.ts` 逐项断言两者一致。

* **只用色板内的颜色**：画布 `canvas`、次级 `soft`、焦块 `sand`、折面 `facet`、白色 `surface`、墨 `ink`、正文 `body`、弱化 `muted`、边框 `line`、球场红 `accent`、荣耀金 `gold`、正向绿 `green`。不新增色相。
* **文字对比度**：`muted` 在画布上只有 3.4:1，仅用于占位符与图标，真实文字一律用 `body`（6.06:1）。
* **红色**：`accent`（`#D83A1E`）在白底 4.62:1，只作填充、图标、色点与大字；红色文字与选中态文字用 `accentHover`（`#BA2F17`，白底 5.99:1）。
* **错误态**：色板只有一个红，错误复用 `accentHover`，不另立危险色。错误始终带文字与 `role="alert"`，不单靠颜色。
* **图标块**：红 `accentHover` 配白图标、绿配白图标、墨配白图标、金与沙配墨图标（金色上白图标只有 2.38:1）。
* **主按钮**：墨底白字（`macos_fiba.md` §4）；红色只用于强调操作。
* **阴影**：基色取色板的暖褐 `rgba(27, 22, 16, …)`，不用纯黑。

## 3. 字体

* 字体栈 `-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "HarmonyOS Sans SC", "Noto Sans SC", "Microsoft YaHei UI", system-ui, sans-serif`。不加载远程字体，也不打包字体文件（ADR 0031）。
* 数字、比分、编码、计数使用 `font-mono`，全局启用 `tabular-nums`。
* 页面大标题 32/40px 字重 700，字距 `-0.025em`；列表行标题 17px 字重 600；正文 16px，行高 1.7；辅助文字不小于 13px。

## 4. 形状与材质

* 圆角只给控件与浮层：弹窗与菜单 `rounded-2xl`、登录面板与输入框 `rounded-xl`、图标块 8–12px、按钮/筛选胶囊/标签 `rounded-full`；内容区块不套圆角卡片，不用 24px 圆角。
* 阴影只给浮层与交互反馈：弹层 `shadow-raised`、悬停上浮 `shadow-lift`、分段滑块 `shadow-selected`；图标块用 `shadow-tile` 的顶部 1px 内高光。内容区块靠细线分隔，不加阴影。
* 毛玻璃只用于固定在边缘的导航：桌面侧栏 `bg-soft/80 backdrop-blur-xl`，手机顶栏 `bg-canvas/90 backdrop-blur-md`，手机底栏 `bg-canvas/85 backdrop-blur-xl`；账号菜单为弹层，同样使用 `backdrop-blur`。内容区不用。

## 5. 布局

* 桌面（`tablet` 起）：左侧 224px 固定导航栏（品牌、四个主栏目、「场边」下的本地工作台、账号），内容列最大宽度 1080px。手机：56px 顶栏加底部五栏，工具入口保留扇形菜单。
* 选中态在桌面栏与手机底栏一致：`sand` 胶囊底、`ink` 加粗文字、一个 `accent` 小红点，同时设置 `aria-current`。胶囊在栏目之间滑动。
* 分组标题用 `UiGroupHeading`：13px 标题加右侧等宽计数，用于工具页的「可使用 / 建设中」分组、学习页和侧栏。
* 入口列表 `ModuleList`：图标块、标题与说明、状态、chevron，平铺在细线之间；分隔线从图标右侧开始。有先后顺序的列表（学习与备考）加等宽序号。
* 工具页把可用工具排在前面、建设中的排在后面。
* 社区页自上而下：标题行（标题与「社区说明」同行）、版块胶囊、计数与搜索工具行、示例声明提示条、平铺讨论列表（回应用左侧细线缩进）；手机端版块入口是搜索行左侧的三条横线按钮。桌面右侧是导读、学习与履职、关于这里，各以墨色细线作标题下划线。

## 6. 动效与交互

* 缓动：`--ease-ios` 用于位移与浮入，`--ease-spring`（轻微过冲）用于选中胶囊、图标缩放与弹出。常规过渡 200ms `ease-out`。
* 入场效果：页面挂载时浮入一次（不随滚动触发）；列表行按序号错开最多 6 项；账号菜单与扇形菜单弹出；回应区用行高 `0fr→1fr` 展开并设置 `inert`；登录方式分段控件的滑块滑动。
* 悬停只换底色或上浮 2px，按压 `scale-95`；系统开启减弱动态效果时，过渡、动画与延迟一律归零。
* 键盘焦点 2px `accent` 实线轮廓；触控目标不小于 44×44 CSS px；骨架屏、网络提示、操作反馈见[前端规约](../agents/coding-standards/frontend.md)。

## 7. 背景动效

动效禁令已在 `macos_fiba.md` 废除，背景动效是正式的版式组成，不再是例外。

* **内容**：右上一块半场线稿（`facet` 色 1.5px 描边，透明度 .55），每 9 秒一枚红色小球沿抛物线投入篮筐，篮筐处泛起一圈涟漪；左下一枚裁判哨子线稿以挂绳点为轴缓慢摆动，哨口每 6 秒扩散两圈声波。纯色，无渐变。
* **位置**：固定在内容之后（`-z-10`），桌面上从侧栏右侧开始，不叠在毛玻璃侧栏之下；不拦截指针，`aria-hidden`，不产生布局位移；导航外壳与登录外壳各挂载一次。
* **性能**：全部运动只改 `transform` 与 `opacity`（合成器线程，可用 `getKeyframes()` 核对）。小球拆成两层元素：外层匀速水平移动、内层先快后慢地抬升再回落，合成出抛物线，不使用主线程的 `offset-path`。背景层 `contain: layout paint style`，只给会动的元素设 `will-change`。
* **可控**：桌面侧栏有「背景动效」开关，手机顶栏与登录页有 44×44 的图标开关，`aria-pressed` 表达状态；偏好保存在 `localStorage`（`referee:backdrop-motion`），默认开启。后台标签页的暂停由浏览器负责。
* **减弱动态**：系统开启「减弱动态效果」时，小球、涟漪与声波不渲染，哨子不摆动，线稿静止。这是可访问性要求。
* **可读性**：线稿对比度刻意压低、位于文字之下；哨子放在左下角并部分出画，避开正文；若仍影响阅读，用户可随时关闭。

## 8. 禁止

任何渐变、色晕与高光层、色板外的颜色、内容区毛玻璃、装饰折面、把内容区块装进白色圆角卡片、背景动效里的实心色块与高对比线条、不能被用户关闭的持续动效、24px 圆角、表情符号、口号式标题、真实文字使用 `muted`、以颜色独立表示状态、第二套主题与单页私有色值。
