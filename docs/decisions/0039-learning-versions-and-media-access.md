# ADR 0039：学习资料不可变修订与按发布关系授权媒体

- 状态：已接受
- 范围：FS-0002 Task 9、[FS-0033](../specs/0033-learning-assets-api.md)
- 关联：[ADR 0021](0021-media-control-plane.md)、[ADR 0014](0014-scoped-authorization-and-audit-foundation.md)、[ADR 0009](0009-database-infrastructure-and-transactions.md)

## 背景

学习资料允许多个分类、多个媒体及后续修订。新草稿不能改变已发布内容，资料下线也不能破坏已有考试/答卷的历史引用。现有媒体入口只有 owner 私有权限，无法凭媒体 ID 判断学习发布关系。Task 9 原规划的迁移编号已经被组织功能使用。

## 决策

1. 新增 `0012_learning_assets.sql`，不改写已应用迁移。learning 模块拥有分类、资料、修订、发布记录和版本关联表。
2. 每次编辑追加不可变版本，包含正文、分类 ID、媒体 ID 和下载策略。逻辑资料分别维护 `latestVersion`、`publishedVersion` 及并发 `revision`。新修订保留原发布指针，发布只允许最新版本；下线撤销普通读取，不删除指针或版本。发布事实单独追加，避免为了填写发布时间修改内容快照。
3. 分类由 `platform.manage` 管理；资料编辑/发布使用 `content.edit`，下线使用 `content.unpublish`，沿用现有单一权限矩阵。分类树移动使用事务 advisory lock，完整检查环及子树深度并按父子顺序更新；数据库触发器和延迟约束兜底。停用保留关联，无有效分类按未分类呈现。
4. 正文首发使用纯文本段落数组，媒体只由显式 ID 引用；不接受任意 HTML 或从正文解析隐藏的媒体引用。新增媒体须为当前编辑本人、platform 目标、learning 用途、available 状态；同资料上一修订已有媒体可由其他编辑保留。发布重新检查分类和媒体类型、核验字节数与默认大小上限。
5. 登录用户（含邮箱未验证者）可读取已发布正文，并通过资料专用入口申请 60 秒媒体访问能力；签名在事务外，返回前重新锁定账号、资料和媒体，核对 revision 并追加审计。在线查看使用 inline，下载使用 attachment 且要求该发布版本允许下载。所有响应 no-store，Bucket 保持私有，无匿名公共 URL。此项扩展 ADR 0021 的学习读者共享限制；不扩展认证、考试或赛后入口，也不宣称具备内容安全扫描。
6. 历史快照管理入口仍要求 `content.edit`，普通用户不可凭版本号访问已下线内容。后续考试模块须从自己的不可变引用和考生授权出发解析旧快照，不把历史管理 API 当成考生访问入口。
7. 已被任一资料版本引用的媒体拒绝通用和治理删除；数据库保留保护同时防止修改对象身份或核验元数据。版本表及关联不可更新/删除，关联表也不能插入快照未声明的 ID。

## 备选方案

原地修改草稿/发布内容增加历史覆盖风险；只保存当前版本无法满足考试历史；把学习媒体改为公开 Bucket 会绕过下线与下载门禁；所有媒体读取通过 API 代理违反资源预算，均未采用。

## 后果

应用没有新增依赖。分类写入全局串行但数据量较小，当前可接受；资料媒体引用占用留存空间，清理须另订历史保留与隔离流程。下载策略只控制服务端是否签发 attachment，不能阻止用户保存浏览器已收到的在线内容；下线前已签发能力仍可能存活至 60 秒到期。真实存储端到端、学习 UI 和考试旧快照授权在后续范围验证。
